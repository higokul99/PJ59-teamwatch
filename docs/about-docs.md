# About docs/ folder
Every repository will consist of docs/ folder which includes the details about the project. 
It also includes the prd.md which will have the requirement of the project.
It also includes the ui-design.md which will have the ui design of the project.
It also includes the test-plan.md which will have the test plan of the project.
It also includes the test-report.md which will have the test report of the project.
It also includes the architecture.md which will have the architecture of the project.

## What is the folder structure folding inside the docs/ ?
docs/ will have sub folder for specific purposes. Here are the following:
1. chat-answers/ : Inside this folder you can store the answers of specific chat answers that the AI gives. On ask to store, then only save the answer inside this folder with chat title as md file's filename.
2. project/ : Inside this we start documenting the project. We will store the prd.md, ui-design.md, test-plan.md, test-report.md, architecture.md inside this folder based on respective portal names.
3. deployment/ : This folder will only consist of information regarding deploying the project in different environments.

### In-depth documentation inside project/ folder
project/ will have sub folder for specific purposes. For example, suppose this was a library management system. Then the sub folder names will be librarian-portal/ or librarian-dashboard/ , student-portal or student-dashboard/ or teacher-portal/ or teacher-dashboard/ and so on. And inside each subfolder, we will have the following documents:
1. prd.md : This folder will only consist of information regarding requirement of the project.
2. ui-design.md : This folder will only consist of information regarding ui design of the project.
3. test-plan.md : This folder will only consist of information regarding test plan of the project.
4. architecture.md : This folder will only consist of information regarding architecture of the project.
